STEP 1

서류 확인 & 스캔

위촉서류와 필수서류가 다 있는지 먼저 확인하고, 스캔해요.

📎 동의서 (이클린동의서) 스캔

위촉서류 뒤쪽에 붙어있는 동의서 2장이 이클린동의서예요. 따로 챙겨서 스캔해요.

동의서 예시 — 모집경력 수집·이용, 제공, 조회 동의서 (2장)
생보 또는 손보만2장 스캔
생보 + 손보 같이4장 스캔
📄 동의서는 PDF로 올려요. 파일명은 아래처럼 저장해요. (ㅇㅇㅇ = 설계사 이름)
위촉 구분동의서 파일명 (PDF)
손보만ㅇㅇㅇ_손보 동의서
생보만ㅇㅇㅇ_생보 동의서
손보 + 생보 같이ㅇㅇㅇ_손생보 동의서

📎 필수서류 스캔

공통 (전원)
✅ 신분증 사본
✅ 통장 사본
✅ 합격증
✅ 수료증
경력자 추가
✅ 경력증명서
✅ 이클린
📄 필수서류는 한 개의 PDF로 합쳐서 올려요. 파일명은 아래처럼 저장해요. (ㅇㅇㅇ = 설계사 이름)
위촉 구분필수서류 파일명 (PDF)
손보만ㅇㅇㅇ_손보
생보만ㅇㅇㅇ_생보
손보 + 생보 같이ㅇㅇㅇ_손생보
STEP 2

IIMS에 서류 첨부

스캔한 서류를 IIMS 구비서류함에 올려요.

IIMS → 인사관리 → 위촉계약서 → [입사서류제출현황]
1
사원 검색
사원명 또는 사번으로 검색해요.
2
[구비서류함] 클릭
검색 결과에서 해당자의 구비서류함을 열어요.
3
위쪽 — 필수서류 첨부 → 저장
스캔한 필수서류를 위쪽 칸에 첨부하고 저장
4
아래쪽 — 동의서 첨부 → 저장
스캔한 이클린 동의서를 아래쪽 칸에 첨부하고 저장
⭐ 핵심

공유링크 [위촉진행] 탭 입력

공유링크를 열어서 [위촉진행] 탭에 정보를 입력해요.

항목입력 방법
접수자총무 이름 입력
사번위촉하는 설계사의 사번
보증보험아래 IIMS 경로에서 확인 (자세한 방법 참고)
고유번호MetPLUS에서 조회 (아래 참고)
생/손MetPLUS에서 조회
3년 경력일수MetPLUS에서 조회

🔍 보증보험 등급 확인 방법

IIMS → 채권관리 → 보증보험 의뢰 및 유지현황 → [보증보험 등급현황]

→ 수수료구간한도액 확인 → 오른쪽 [보증보험 계산기] 눌러서 등급 확인

🔍 MetPLUS 경력 조회 방법

MetPLUS → 위해촉관리 → 협회정보조회 → 보험경력조회
1
자료요청 체크
주민번호 입력 → 동의여부: Y → 조회목적: 설계사등록관련 → 조회
2
결과조회 체크 후 한 번 더 조회
결과조회 체크하고 조회 버튼 한 번 더 눌러요.
3
확인할 것
고유번호 / 말소일 / 경력일수 확인 가능!
⚠️ 입력 다 하고 → 필수서류, 말소일까지 다 체크했는지 꼭 확인!
STEP 4

공유링크 [위촉발송] 탭

공유링크에서 [위촉발송] 탭을 열어요.

1
사번 입력
사번만 넣으면 나머지 정보는 자동으로 불러와져요.
2
색칠된 부분만 입력
핑크색, 연두색 부분만 입력 가능해요. 나머지는 수정 불가.
STEP 5

협등위 파일 작성 & IIMS 등록

협등위 파일을 작성한 뒤 IIMS에서 일괄등록해요.

1
협등위 파일 작성
위촉 대상자 정보를 협등위 파일에 정리해요.
▶ 협등위 파일 작성 영상 (1분 35초)
2
IIMS에서 파일 첨부
아래 경로에서 일괄등록으로 파일을 올려요.
IIMS → 인사관리 → 보험설계사협회등록/위촉 → 일괄등록 → 파일첨부
